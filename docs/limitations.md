# Research Limitations

This document outlines the known limitations of the ResearchGuard AI system and its underlying Phase 5 Controlled Research Experiment.

## 1. Domain and Format Mismatch
- **SciFact Abstracts vs. Runtime PDF Chunks**: The Phase 5 ML model was trained and evaluated on highly curated, dense scientific abstracts from the SciFact dataset. In the runtime application, the model evaluates arbitrary PDF text chunks generated via PyMuPDF and basic token splitting. This structural difference limits the direct generalizability of SciFact metrics to the runtime pipeline.
- **Domain Mismatch**: SciFact is restricted to specific scientific domains. The model's performance on out-of-domain runtime documents (e.g., legal contracts, financial reports) is untested.

## 2. Evaluation Constraints
- **Absence of PDF Ground Truth**: The runtime application lacks a labeled ground-truth dataset for PDF chunk verification. It relies on the offline SciFact evaluation as a proxy.
- **Binary SUPPORT/CONTRADICT Evaluation**: The verification model forces a binary classification. It does not account for nuanced stances, partial support, or "NOT ENOUGH INFO" scenarios (which were explicitly excluded from the binary mapping).
- **Class Imbalance in SciFact**: The SciFact dataset possesses a natural class imbalance (64.25% SUPPORT vs. 35.75% CONTRADICT). While `class_weight="balanced"` mitigates this during training, the evaluation metrics are influenced by this imbalance.

## 3. Pipeline Dependencies
- **Retrieval Dependency**: Claim verification accuracy is strictly bounded by retrieval quality. If the upstream vector search retrieves irrelevant evidence, the verification model will operate on flawed premises.
- **Single Evidence Selection**: The verification step depends entirely on the single most relevant chunk retrieved. It cannot currently synthesize evidence across multiple chunks or pages.
- **Local LLM Dependency**: The extraction of claims relies on the local `qwen2.5:7b-instruct` model. Hallucinations or malformed claims generated by the LLM cascade directly into the verification logic.

## 4. Modeling Limitations
- **Limitations of Cosine-Threshold Baseline**: The baseline model establishes a static, one-dimensional threshold tuned on the training data. This simplicity makes it highly susceptible to semantic overlap that lacks logical entailment (e.g., predicting SUPPORT simply because words match).
- **Confidence Interpretation**: The Logistic Regression `predict_proba` output is presented as a "confidence score" in the UI. This is a statistical probability derived from feature distribution, not a calibrated measure of absolute truth or epistemic certainty.
